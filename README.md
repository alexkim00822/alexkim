# Alex Kim: personal website

This folder is a ready-to-publish GitHub Pages site. There is no build step.

## Publish

1. Sign in to GitHub and create a new public repository.
2. Click "uploading an existing file". From inside this folder, select `index.html`, `README.md`, and the `assets` folder, and drag them into the browser window. Click "Commit changes".
3. Open Settings, then Pages. Under "Build and deployment", choose "Deploy from a branch", pick `main` and `/ (root)`, and click Save.
4. After a minute or two, the site is live at https://alexkim00822.github.io/alexkim/

## Update

Open `index.html` on GitHub, click the pencil icon, edit, and click "Commit changes". To add a photo, upload it to the `assets` folder.

## Privacy tip

Before uploading, open GitHub Settings, then Emails, and turn on "Keep my email addresses private" so the commit history does not show a personal email.
